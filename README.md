# smart-home-
High-Performance Digital Smart Home SoC  A modular, synthesizable Verilog RTL implementation of a Smart Home System-on-Chip. All sensing, decision-making, and actuation run in parallel hardware, with no processor or software polling. The design targets the Xilinx Artix-7 (Digilent Basys3) and is portable to Intel Cyclone and DE10-Lite.
